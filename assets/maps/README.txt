# 40 级地图模板 — 重要

## 不要截整屏！

当前若使用 1920×1080 全屏图，HUD/血量/角色位置一变就匹配失败。

请只截 **能区分两张图的特征区域**（建议 200×200 ~ 400×400）：

| 文件 | 建议截取 |
|------|----------|
| 40-1.png | 左侧金色齿轮墙 / 小地图形状等 40-1 独有特征 |
| 40-2.png | 走廊尽头亮光 / 小地图形状等 40-2 独有特征 |

## 测试

```powershell
python tools/test_match.py
```

在 40 级战斗内截图后，查看 40-1 / 40-2 的匹配分数，应 > 0.55。

## 走位

| 地图 | 流程 |
|------|------|
| 40-1 | 先进图按 E → d/w/a 走位 |
| 40-2 | 先进图按 E → w 走位 |
